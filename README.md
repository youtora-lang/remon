# remon 🍋

中学1年生向けの5教科テスト対策学習アプリ（PWA）。
教科書に準拠した4択クイズで、間隔反復（忘れたころに復習）によって自然に定着させる。

## 対応教科書

| 教科 | 出版社 | 教科書名 |
|---|---|---|
| 英語 | 東京書籍 | NEW HORIZON English Course 1 |
| 数学 | 啓林館 | 未来へひろがる数学 1 |
| 国語 | 光村図書 | 国語 1 |
| 理科 | 啓林館 | 未来へひろがるサイエンス 1 |
| 社会・地理 | 帝国書院 | 中学生の地理 世界の姿と日本の国土 |
| 社会・歴史 | 育鵬社 | 新しい日本の歴史 |

## 主な機能

### 学習
- **今日の 20 remon**：全教科から、復習どきの問題と未学習の問題を中心に20問出題
- **今日の remon**：教科ごとに、間隔反復（忘却曲線）で出すべき問題を出題
- **単元を選ぶ**：単元を指定してまとめて練習
- **まちがえた問題を復習**：直前の回で間違えた問題だけをもう一度
- 4択はすべて教科書準拠。誤答にはよくある誤解・ミスを仕込み、解説で正誤の理由を示す

### 進捗管理
- 3色バッジ：🟡未学習 / 🔴おすすめ（復習どき） / 🟢完了 / ⚪停止中（除外中）
- 単元ごとに🍋ボタンで「今日の出題対象」から外せる（テスト範囲の絞り込みに利用）
- 単元の選択状態は解除するまで保持される
- ホーム画面に教科ごとの学習進捗（学習済み問題数・正答率）を表示
- 週間バーチャート（目標達成日は緑、未達成はオレンジ、今日は枠付き）

### 学習履歴の堅牢性
- 履歴は「問題文」をキーに保存（`histByText`）。問題の追加・並べ替え・構造変更があっても、
  正誤記録・復習タイミングは引き継がれる（`PRELOAD_STRUCT_VERSION` を上げても消えない）

### UI / 操作性
- ホーム画面：上部（タイトル・今日の20問・週グラフ）固定、教科一覧のみスクロール、
  下部（使い方ガイド）固定
- 教科ページ：上部（学習モード選択）・下部（はじめるボタン）固定、単元一覧のみスクロール
- スマホの戻るボタンと画面の←ボタンは同一の動作（`navBack`）。
  「クイズ中→単元展開状態の教科ページ」「単元展開→閉じる」「閉じた状態→ホーム」と、
  画面単位ではなく操作単位で1step戻る。ホームより手前でアプリが閉じることはない
- 全ページ下部にフッター（更新日時・Made by Chii）

## ファイル構成

```
index.html   本体（PWA本体・全ロジック・問題データを内包）
sw.js        Service Worker（キャッシュ管理）
manifest.json / icon-192.png / icon-512.png（別途）
```

## データの仕組み

- `PRELOAD`：教科・単元・問題（`question` / `choices`（先頭が正解） / `explanation`）の配列
- `PRELOAD_STRUCT_VERSION`：単元構成を変更したら上げる。上げても学習履歴（正誤・復習日）は
  問題文ベースで引き継がれる
- `state.history[教科][問題ID]`：間隔反復のための正誤・次回出題日
- `state.selectedUnits[教科]`：単元選択モードでの選択状態（教科ごとに保持）
- `state.excludedUnits`：🍋オフ（停止中）にした単元
- localStorage に保存。レモン数・連続記録・週間記録は構造変更時も保持される

## 開発メモ

- 問題は日本語の指示文→4択（英語は日本語文の英訳、他教科は内容理解・計算など）
- 誤答は「ありがちな間違い」を採用し、解説でその誤りの理由を明示する
- 1つの教科書出版社の指導計画・目次に沿って単元を区切る（学校の進度に合わせやすくするため）
