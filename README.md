# 🍋 remon

中学生向けの4択フラッシュカード暗記アプリ。教科書の進度に合わせて問題を追加し、忘却曲線で復習できる。

## 特徴

- **6教科対応** — 国語・数学・理科・社会・英語・技保音美。教科ごとに背景色が変わる。
- **今日の20問** — ホーム最上部のボタンを押すだけで、全教科から20問を自動でピックアップ。未着手・定着していない問題を優先して出題する。
- **忘却曲線で復習** — 正解すると次の出題間隔が伸び（1→3→7→14→30日）、まちがえると1日後に戻る。
- **単元ごとの除外** — 各単元の🍋ボタンで「今日の20問」の対象から外せる（✕表示）。
- **解説の表示切り替え** — 「まちがえた時だけ」か「いつも出す」を設定で選べる。
- **やる気を保つしくみ** — 連続学習日数🔥・累計正解数・教科ごとの正答率・たまっていくレモン🍋。
- **文字サイズ変更** — 小・中・大の3段階。
- **PWA対応** — ホーム画面に追加すればアプリのように使える。オフラインでも動く。

## 使い方

### 問題を追加する

1. ホームの📥（インポート）を開く
2. JSON形式の問題データを貼り付ける
3. 取り込むと教科ごとに問題が追加される（重複は自動でスキップ）

### 問題データの形式

```json
{
  "subject": "kokugo",
  "unit": "教科書の単元名",
  "questions": [
    {
      "question": "問題文",
      "meaning": "正解",
      "choices": ["正解", "ダミー1", "ダミー2", "ダミー3"],
      "explanation": "解説文"
    }
  ]
}
```

### subject（教科）のキー

| キー | 教科 |
|------|------|
| kokugo | 国語 |
| sugaku | 数学 |
| rika | 理科 |
| shakai | 社会 |
| eigo | 英語 |
| sonota | 技・保・音・美 |

- `choices` の配列はそのまま4択に使われる（1つ目が正解である必要はなく、`meaning` と一致する選択肢が正解判定される）。
- `unit` は教科書の単元名に合わせると、どこを学習中か分かりやすい。

## 学習モード

- **今日の20問** — 全教科横断。未着手→定着していない→その他の順で20問。
- **今日の分** — その教科で復習期限が来た問題。
- **単元** — 単元を選んで出題。タップで選択（複数可）。

## ファイル構成

| ファイル | 役割 |
|----------|------|
| index.html | アプリ本体（単一ファイル） |
| sw.js | Service Worker（オフライン対応・キャッシュ管理） |
| manifest.json | PWA設定 |
| icon-192.png / icon-512.png | アプリアイコン |

## デプロイ（GitHub Pages）

1. リポジトリにファイル一式をpush
2. Settings → Pages で公開
3. `manifest.json` の `start_url` と `scope` を公開先のパスに合わせる（例：`/remon/`）

### 更新が反映されないとき

`sw.js` の `CACHE_NAME`（例：`remon-v5`）の数字を上げてpushすると、古いキャッシュが破棄されて最新版が読み込まれる。

## データの保存先

学習履歴や設定はブラウザの localStorage に保存される。端末内に保存され、外部には送信されない。
